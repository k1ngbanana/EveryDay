# Node

## 安装

### 1. 通过 NodeSource 仓库安装 Node.js 22

通过 NodeSource 仓库安装 Node.js 22。首先，添加 Node.js 22 的仓库：

```bash
curl -sL https://rpm.nodesource.com/setup_22.x | sudo bash -
```

然后，安装 Node.js 22：

```bash
sudo dnf install nodejs -y
```

### 2. 验证安装

```bash
node -v
npm -v
```
